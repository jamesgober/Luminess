Blocks and fallbacks: a value that renders itself can now fail gracefully anywhere in a page, and every failure is reported.

## Highlights

- **Fallback text in the template.** `{{ page.stock | fallback("Unavailable") }}` writes that text, escaped, when the block fails, in place of the block's own fallback.
- **Text forms.** `View::text` gives a block a plain-text form, so it can go in an attribute, a URL, a script, or a style; the engine escapes it for the place. Before, a block outside HTML text was a compile error.
- **Every failure reported.** `Rendered::failures` keeps the reason of each failed block (up to 16) for the log; `Rendered::fallbacks` counts them all.
