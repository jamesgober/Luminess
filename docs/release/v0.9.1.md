The web-net integration, behind the new `web-net` feature. The default build still depends on nothing.

## Added

- **`Engine<V>` is a `web_net::Render`**, with the application's own view type: a page handler's `&V` goes straight to the compiled templates. Template names are resolved when the web-net app is built, so a missing template stops it from starting; the ids stay valid across `Engine::reload`, and rendering by id reads one array entry with no shared write.
- **`luminess::web::Theme`** adds error pages from an `Engine<ErrorView>`: `error/<status>`, then `error`, then web-net's built-in page.
- Error codes for web-net's events: `luminess.not_found` (a template a reload removed) and `luminess.too_large`.
