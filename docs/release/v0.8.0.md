Diagnostics and limits: errors that point at the column, a development error page, output and template-size limits, and a check for editors and CI.

## Highlights

- **Compiler-style reports.** `CompileError::report` shows each problem with its place, the source line, and a caret under the column. `CompileError::to_html` gives the same as an escaped `<pre>` block for a development error page.
- **Output limit.** `Builder::max_output(bytes)` stops a render that would write more, removes what it wrote, and returns `RenderErrorKind::TooLarge`.
- **Template-size limit.** `Builder::max_template_size(bytes)`, 1 MiB by default.
- **`Builder::check`** compiles a theme and keeps nothing, without consuming the builder.

## Fixed

- Nested `for` loops took exponential time to compile (each body was compiled twice; 20 levels took about a second). Found by the hour-long fuzz run; compiling is now linear in nesting depth.
