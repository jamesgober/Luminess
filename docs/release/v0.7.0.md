Performance: renders on many threads no longer contend, escaping is faster, and a comparison with other Rust engines is included.

## Highlights

- **No shared writes per render.** Each thread keeps the engine's current template set and checks a generation counter, so a render takes no lock and makes no shared atomic write. Reloads are seen by the next render on every thread. Under 16 threads, the engine's cost over a no-engine control fell from about 1.1-1.5 µs to 0.3-0.6 µs per render.
- **Faster escaping.** The HTML escaper scans eight bytes at a time (about 4 GB/s on text with nothing to escape, up from 1.6); the URL escapers copy runs of safe bytes.
- **Smaller costs:** a fast hash for template names, a jump table in `view!`, and a direct path for plain field outputs.
- **`benches/compare`** renders the typical page with Askama (about 4 µs), Luminess (about 9 µs), Tera (about 28 µs), and MiniJinja (about 45 µs). Askama generates Rust code at build time and cannot reload or use startup schemas; Tera and MiniJinja convert the data through serde on every render.

No API changes.
