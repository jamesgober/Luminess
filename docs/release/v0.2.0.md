The rebuild. Luminess now compiles templates once, at startup, against typed views, and renders straight into your buffer with escaping chosen for each place in the HTML.

## Highlights

- **Checked at startup.** Unknown names, fields, filters, and templates, type mismatches, and unsafe output places are compile errors with the template, line, column, and a suggestion. Every error of a set is reported at once.
- **Contextual escaping.** HTML text, quoted attribute values, `<title>`/`<textarea>`, and URL attributes each get their own escaper, picked at compile time. `javascript:` and other schemes are blocked at the start of a URL. Unquoted attributes, comments, tag and attribute names, `srcdoc`, scripts, and styles are refused.
- **Typed views, no data conversion.** `View`, `Schema`, `Value`, and the `view!` macro; field ids are resolved by the compiler. No JSON, no serde, no maps.
- **Blocks that render themselves**, with rollback and a fallback when they fail, and `{% try %}`/`{% fallback %}` for custom markup.
- **Live reload.** `Engine::reload` swaps in a new set; a set with errors is refused and the running one stays.
- **Zero dependencies.** MSRV 1.85.

## Numbers

A typical 10.8 KiB page (navigation include, 2 KiB body, 20 related posts) renders in about 9 µs; one value in about 80 ns; compiling the page and its include takes about 35 µs.

## Checks

Fuzzed (`compile`, `escape` targets), property-tested escaping (2,000 cases per property), CI on Linux, macOS, and Windows with stable and 1.85.

The template syntax may still change before 0.5.0. See the [README](https://github.com/jamesgober/Luminess#templates).
