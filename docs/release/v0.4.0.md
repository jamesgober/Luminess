Composition: layouts, partials with their own root, and themes loaded from a folder.

## Highlights

- **Layouts.** `{% extends "base" %}` with `{% block name %}...{% endblock %}` and `{{ super() }}`. Chains can be several levels deep and blocks can nest. Everything is resolved and checked at startup: an unknown parent, a cycle, a block the chain does not have (with a "did you mean"), stray text in an extending template, or a block that would end up inside itself is a compile error.
- **Partials with their own root.** `{% include "card" with post %}` renders `card` with `post` as its root value, and checks `card` against `post`'s fields.
- **Themes from a folder.** `Builder::directory("themes/default", "html")` adds every `.html` file below the folder, named by its path: `partials/nav.html` becomes `partials/nav`. Reload a theme with `engine.reload(Engine::builder().directory(..)?)`.

Layouts are inlined at compile time, so they cost nothing per render.
