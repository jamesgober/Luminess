The API freeze for 1.x and the pre-1.0 polish pass. This is the release candidate: the public API is what 1.0 is planned to ship, and 1.0 itself waits for its own decision.

## Changes

- **The template syntax is frozen.** `docs/SYNTAX.md` now spells out the `loop` fields (`loop.index` counts from 1) and exactly what counts as a failing block and what `try` discards. Later changes come with a migration note.

- **CSS values** may use `rgb`, `rgba`, `hsl`, `hsla`, `calc`, `min`, `max`, `clamp`, and `var` around plain text, so `rgb(10, 20, 30)` and `calc(100% - 2em)` work. Any other function, `url(` included, and comment markers are still replaced with `blocked`.
- **The `view` module is private.** Everything public was already at the crate root.

## Documentation

- `docs/SYNTAX.md`: the template syntax.
- `docs/API.md`: the public API on one page.
- `docs/SECURITY.md`: what each escaper guarantees, and the known, accepted limits.
- `docs/PERFORMANCE.md`: what a render does, and the measurements.
